# 0005 — Blog

## Decision

- Public `/blog` and `/blog/[slug]` read published posts from the admin-auth
  Supabase project (service role, server-side only) (ISR, 60s).
- Posts are written in Markdown, rendered with react-markdown (raw HTML
  ignored).
- The editor lives in the main admin as the staff app `wimm` ("Where Is My
  Money?") at `/admin/wimm/blog`, using the same email magic-link staff login as
  Henstel.
- `/wimm/admin` is unchanged: promo offers only, own Google login.
- Author = creator; reviewer = a different staff member who edits. Names come
  from `staff.display_name`.
- Authorization: `requireStaffAccess("wimm")` in every Server Action; pages use
  a UX-only guard.

## SQL

- `docs/sql/blog.sql` — admin-auth project (same as staff).
- `docs/sql/staff_wimm_access.sql` — admin-auth project.

## Phase 2 — comments, reactions, views

- **Comments:** anonymous (name + text, no email), Turnstile + honeypot, stored
  `pending`, shown only after a staff member approves them at
  `/admin/wimm/blog/comments`. Rendered as plain text, never Markdown/HTML.
- **Likes / dislikes:** one reaction per visitor per post, tracked by an
  httpOnly cookie (`br_<postId>`); choosing the same one again removes it, the
  other switches it.
- **Views:** counted from the browser on page load (so crawlers aren't counted
  and the ISR page stays cacheable), once per visitor per post per 24h via
  cookie (`bv_<postId>`).
- **Counters** are updated by SQL functions (`blog_record_view`,
  `blog_apply_reaction`) so concurrent visitors can't lose updates, and never
  touch `updated_at`.
- **SQL:** `docs/sql/blog_phase2.sql` (admin-auth project, after `blog.sql`).

### Alternatives considered

- Cookie-less counting (IP hashing): needs a stored identifier for every
  visitor; rejected for privacy and simplicity.
- Third-party comments (Disqus, Giscus): rejected — ads/tracking or GitHub
  accounts, and no control over moderation.

### Consequences

- A visitor who clears cookies can count a view or reaction again. Accepted for
  an anonymous counter.
- No email notification on new comments yet — the admin home shows a pending
  count instead.
- Counts shown on the cached page can be up to 60s old; the browser refreshes
  them on load.
